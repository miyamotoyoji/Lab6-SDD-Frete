# Constituição do projeto

1. Usar Python 3.14 ou superior e pytest para os testes.
2. Manter código simples, sem dependências de execução externas.
3. A especificação em `specs/checkout_frete.md` é a fonte de verdade.
4. Referenciar os requisitos nos testes e na implementação.
5. Aplicar RED → GREEN; mudanças de regra começam pela especificação.
6. Não implementar cupons, regiões, persistência ou logs sem requisito aprovado.
7. Versionar alterações de regra, código e testes no mesmo commit.
