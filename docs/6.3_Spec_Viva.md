3. Executados os novos testes sobre o código antigo: **4 falhas e 12 sucessos**, comprovando que detectam a mudança pendente. Saída: [6.3_RED.txt](../evidencias/6.3_RED.txt).
4. Atualizado o limite na implementação para 250.
5. Nova execução: **16 testes passaram**. Saída: [6.3_GREEN.txt](../evidencias/6.3_GREEN.txt).
6. Especificação, implementação e testes versionados juntos em um único commit da branch `feat/limite-frete-250`.
